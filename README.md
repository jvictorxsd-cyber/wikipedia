## Conteúdo

- `wiki/`: documentação com hierarquia e links internos convertidos para Markdown relativo.
- `SUMMARY.md`: navegação das páginas.
- `media-manifest.json`: catálogo de mídias, URLs originais e metadados.
- `covers.json`: imagens de capa e posições.
- `download_media.py`: ferramenta opcional para baixar as mídias originais para `assets/` e substituir seus links por caminhos relativos.

**Importante:** para manter o ZIP leve, as 48 mídias originais estão referenciadas por URLs do GitBook e **não acompanham inicialmente o arquivo compactado**. Execute `python download_media.py` com internet para criar uma cópia local das mídias. Algumas URLs podem requerer acesso ou expirar; confira o resultado do script. Mídias externas, como vídeos do YouTube ou imagens do Imgur, continuam como links externos.

Este backup não inclui configurações privadas, histórico de edições, comentários ou dados administrativos do GitBook.
