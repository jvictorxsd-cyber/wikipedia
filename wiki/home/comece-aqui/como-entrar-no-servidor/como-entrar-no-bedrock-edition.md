# 📱 Como entrar no Bedrock Edition

Está jogando **Minecraft Bedrock Edition** pelo celular, tablet ou computador? Nesta página, você aprende a adicionar o **DropMC** à sua lista de servidores e começar sua aventura no Survival.

O procedimento pode variar um pouco conforme o dispositivo e a versão do Minecraft, mas os dados de conexão permanecem os mesmos.

## 🌐 Informações do servidor

| Campo                 | O que preencher         |
| --------------------- | ----------------------- |
| **Nome do servidor**  | `DropMC`                |
| **Endereço / IP**     | `dropmc.gg`             |
| **Versão necessária** | Mais recente disponível |
| **Porta**             | `19132`                 |

> **Importante:** o endereço `dropmc.gg` é utilizado tanto no Java quanto no Bedrock. A porta **19132** é a informação adicional para o Bedrock.

**Versão do Bedrock:** mantenha o Minecraft atualizado para a **versão mais recente disponível**, pois é essa a versão utilizada para acessar o DropMC.

## ✅ Antes de começar

1. Abra o **Minecraft Bedrock Edition** no seu dispositivo.
2. Atualize o Minecraft Bedrock para a **versão mais recente disponível** e verifique se está com acesso à internet.
3. Caso o jogo solicite, entre na sua **conta Microsoft** para acessar recursos multijogador.
4. Tenha em mãos o IP e a porta indicados acima.

## 📝 Passo a passo para se conectar

**1. Abra o Minecraft Bedrock Edition.** Aguarde o carregamento da tela inicial.

**2. Selecione `Jogar`.** É nessa área que você encontra seus mundos e as opções para jogar online.

**3. Acesse a aba `Servidores`.** Procure a opção de **adicionar servidor** ou **adicionar servidor externo**. O nome e a posição da opção podem variar dependendo do dispositivo.

**4. Escolha um nome para identificar o servidor.** No campo de nome, digite `DropMC`.

**5. Informe o endereço.** No campo **Endereço do servidor** (ou **IP**), preencha `dropmc.gg`.

**6. Configure a porta.** Digite `19132` no campo correspondente à porta.

**7. Salve as informações e entre.** Selecione o DropMC na sua lista e toque em **Entrar no servidor**, **Conectar** ou na opção equivalente exibida pelo jogo.

## ❓ Perguntas frequentes

### Não aparece a opção de adicionar servidor. O que fazer?

Em algumas plataformas, especialmente **consoles**, a interface pode não oferecer a mesma opção de adicionar servidores externos disponível em celulares ou computadores. Verifique as opções do seu dispositivo e peça orientação no Discord do DropMC.

### Qual porta devo usar?

No **Minecraft Bedrock Edition**, utilize a porta **`19132`**.

### Posso usar o mesmo IP do Java?

Sim. As duas edições utilizam **`dropmc.gg`**.

### O servidor não conecta. O que devo verificar?

Confira se escreveu o IP corretamente, se inseriu a porta **19132** e se sua internet está funcionando. Também vale conferir se o Minecraft apresenta alguma mensagem de incompatibilidade ou erro de conexão.

## 💬 Precisa de ajuda?

Se não conseguir se conectar, envie uma mensagem no [**Discord oficial do DropMC**](https://discord.gg/dropmc). Informe qual dispositivo você usa e, se possível, compartilhe uma imagem do erro apresentado.
