# 🎮 Como entrar no servidor

Quer começar sua aventura no **DropMC**? Você está no lugar certo! Este guia reúne tudo o que precisa saber para acessar nosso servidor Survival, tanto pelo **Minecraft Java Edition** quanto pelo **Minecraft Bedrock Edition**.

A conexão é simples, mas o caminho muda um pouco conforme a edição que você utiliza. Escolha abaixo o guia adequado e acompanhe cada etapa.

## 🌐 Dados para conexão

| Informação               | Java Edition            | Bedrock Edition                                             |
| ------------------------ | ----------------------- | ----------------------------------------------------------- |
| **Endereço do servidor** | `dropmc.gg`             | `dropmc.gg`                                                 |
| **Versão compatível**    | **1.21.11 ou superior** | **Versão mais recente disponível**                          |
| **Porta**                | Padrão do Java          | `19132`                                                     |
| **Dispositivos**         | Computador              | Celular, tablet, Windows Bedrock e dispositivos compatíveis |

**Versões:** no Java, utilize a **1.21.11 ou superior**; no Bedrock, mantenha o jogo **sempre atualizado para a versão mais recente**.

**Importante:** Java e Bedrock utilizam o mesmo endereço, mas, no Bedrock, você deve informar também a porta **19132**.

## 🧭 Escolha sua edição

### 🖥️ Minecraft Java Edition

Joga pelo computador? O guia do **Java Edition** mostra onde adicionar o servidor na lista de multijogador e como se conectar usando o endereço do DropMC.

[➡️ **Como entrar no Java Edition**](como-entrar-no-java-edition.md)

### 📱 Minecraft Bedrock Edition

Joga pelo celular, tablet ou pela versão Bedrock? Aprenda a acessar a área de servidores, inserir o IP e configurar a porta correta.

[➡️ **Como entrar no Bedrock Edition**](como-entrar-no-bedrock-edition.md)

## ✅ Antes de tentar se conectar

* Verifique se o Minecraft está instalado e funcionando no seu dispositivo.
* Certifique-se de que sua conexão com a internet está ativa.
* Confira se selecionou a **edição correta** do jogo.
* Digite o endereço exatamente como informado: **`dropmc.gg`**.
* Se estiver no Bedrock, confirme a porta **`19132`**.

> **Atenção:** alguns dispositivos, especialmente consoles, podem apresentar diferenças no menu de servidores ou restrições para adicionar servidores externos.

## 💬 Não conseguiu entrar?

Caso apareça uma mensagem de erro, confira novamente o endereço e os dados de conexão. Se o problema continuar, entre em nosso [**Discord oficial**](https://discord.gg/dropmc) e procure a equipe de suporte. Sempre que possível, informe qual edição você usa e envie uma captura da mensagem de erro.
