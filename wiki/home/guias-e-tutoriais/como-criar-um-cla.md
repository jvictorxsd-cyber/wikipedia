# Como criar um clã

No DropMC, você pode criar um **clã** para jogar com amigos, organizar projetos e participar de atividades competitivas. Para começar, é necessário possuir **10.000 coins**.

## 1. Tenha 10.000 coins

A criação de um clã custa **10.000 coins**. Confira se você possui esse valor antes de iniciar.

Se precisar juntar moedas, consulte [Como ganhar dinheiro](como-ganhar-dinheiro.md).

## 2. Digite o comando de criação

Abra o chat do Minecraft e utilize:

`/clan criar <tag do clan> <nome do clan>`

Substitua os campos pela tag e pelo nome que deseja utilizar.

**A tag deve conter exatamente 3 caracteres.** Escolha uma abreviação que identifique seu grupo.

## 3. Escolha a cor da tag

Depois de utilizar o comando, será aberto um menu para escolher a **cor da tag do clã**.

* **Cinza:** é a cor disponibilizada gratuitamente por padrão.
* **Outras cores:** devem ser adquiridas utilizando **Cash**.

Você pode continuar com a cor cinza, sem precisar gastar Cash na personalização.

## 4. Escolha a bandeira do clã

Na etapa seguinte, selecione a bandeira que representará seu grupo.

* **8 bandeiras gratuitas:** disponíveis por padrão.
* **Bandeira personalizada:** disponível pelo custo de **100 Cash**.

Escolha uma das opções para concluir a personalização.

## 5. Conclua a criação

Após escolher a cor e a bandeira, **seu clã estará criado**.

Você poderá convidar outros jogadores com `/clan convidar <jogador>`, e eles poderão aceitar o convite com `/clan aceitar [convite]`.

**Limite:** cada clã pode possuir até **10 integrantes**.

## Depois de criar o clã

Alguns comandos úteis para começar são:

| Comando                    | Função                                   |
| -------------------------- | ---------------------------------------- |
| `/clan convidar <jogador>` | Convida um jogador para o clã.           |
| `/clan sethome`            | Define a base do clã na posição atual.   |
| `/clan home`               | Teleporta para a base do clã.            |
| `/clan chat`               | Ativa ou desativa o modo de chat do clã. |
| `/clan info`               | Exibe informações sobre o clã.           |

Para conhecer as demais opções de administração, alianças e rivalidades, consulte a página [Clãs](../sistemas-do-servidor/clas.md) e a seção [**Comandos** ](../comandos/clas.md)da Wiki.

## Precisa de ajuda?

Se tiver dúvidas durante a criação, procure a equipe no [Discord oficial do DropMC](https://discord.gg/dropmc).
