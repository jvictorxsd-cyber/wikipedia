# 📔 Comandos

Os comandos permitem acessar e utilizar diversas funcionalidades do DropMC diretamente pelo chat do Minecraft.

Nesta seção, você encontra os principais comandos disponíveis no servidor, organizados por categoria para facilitar a consulta.

## Categorias de comandos

### [Comandos gerais](comandos-gerais.md)

Consulte os comandos relacionados a teletransporte, economia, comunicação, kits, cosméticos, correios, lojas e outras funcionalidades do Survival.

### [Terrenos e proteções](terrenos-e-protecoes.md)

Encontre os comandos para criar, administrar e configurar terrenos protegidos, incluindo permissões e gerenciamento de áreas.

### [Geradores](geradores.md)

Conheça os comandos disponíveis para gerenciar permissões de outros jogadores nos seus geradores de monstros.

### [Clãs](clas.md)

Consulte os comandos para criar e administrar clãs, convidar integrantes, definir bases, utilizar o chat privado e estabelecer alianças ou rivalidades.

### [Contas e segurança](contas-e-seguranca.md)

Encontre os comandos relacionados à autenticação, proteção de conta e vinculação ao Discord.
