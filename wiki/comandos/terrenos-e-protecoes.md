# Terrenos e proteções

Nesta página você encontra os comandos para jogadores exibidos na ajuda do sistema de terrenos do DropMC, conforme as capturas de tela do jogo.

## Criar e selecionar terrenos

Para começar, utilize `/kit terreno` para obter a pá de proteção. Marque um ponto com o **botão direito** e outro com o **botão esquerdo**. Depois, execute `/terreno criar` ou **pressione F com a pá em mãos** para finalizar a criação.

## Lista de comandos

| Comando                         | Descrição                                                                                     |
| ------------------------------- | --------------------------------------------------------------------------------------------- |
| `/terreno`                      | Abre o menu do terreno em que você está.                                                      |
| `/terreno ajuda`                | Lista os comandos de terreno disponíveis para você.                                           |
| `/terreno banidos`              | Lista os jogadores banidos do terreno em que você está.                                       |
| `/terreno banir <jogador>`      | Proíbe um jogador de entrar no terreno em que você está.                                      |
| `/terreno cancelar`             | Cancela a seleção atual, removendo as posições definidas.                                     |
| `/terreno convidar <jogador>`   | Convida outro jogador para ser membro do terreno em que você está.                            |
| `/terreno convites`             | Exibe a lista de convites pendentes para o terreno em que você está.                          |
| `/terreno criar`                | Cria um terreno com base na seleção atual.                                                    |
| `/terreno deletar`              | Deleta o terreno em que você está.                                                            |
| `/terreno desbanir <jogador>`   | Permite que um jogador banido volte a entrar no terreno em que você está.                     |
| `/terreno editar`               | Entra no modo de edição do terreno em que você está.                                          |
| `/terreno info`                 | Exibe informações sobre o terreno em que você está.                                           |
| `/terreno listar`               | Exibe uma lista dos terrenos que você possui ou dos quais é membro.                           |
| `/terreno pos1`                 | Define a primeira posição da seleção no bloco em que você está.                               |
| `/terreno pos2`                 | Define a segunda posição da seleção no bloco em que você está.                                |
| `/terreno sair`                 | Sai do terreno em que você está, removendo você da lista de membros.                          |
| `/terreno salvar`               | Salva a seleção editada como os novos limites do terreno.                                     |
| `/terreno selecionar <tamanho>` | Define ambas as posições da seleção, formando um quadrado centrado no bloco em que você está. |
| `/terreno seletor`              | Recebe a ferramenta de seleção de terrenos.                                                   |
| `/terreno sethome`              | Define a posição de home do terreno em que você está.                                         |

## Comandos de criação e seleção

* `/kit terreno`: recebe a pá de proteção pelo kit.
* `/terreno seletor`: recebe a ferramenta de seleção pelo sistema de terrenos. O item possui **recarga de 10 segundos**, conforme exibido no jogo.
* `/terreno pos1` e `/terreno pos2`: definem as posições usando o bloco onde você está.
* `/terreno selecionar <tamanho>`: cria uma seleção quadrada de tamanho informado, centrada na posição atual.
* `/terreno criar`: confirma a seleção e cria o terreno.
* **Tecla F com a pá de proteção em mãos:** alternativa para concluir a criação após selecionar os pontos.

## Administração de terrenos

Os comandos de convite, banimento, saída, edição, exclusão e definição de home aparecem na ajuda do plugin. Utilize a página [**Sistemas do servidor → Terrenos e proteções**](../sistemas-do-servidor/terrenos-e-protecoes.md) para conhecer as opções de proteção e expansão de área.
