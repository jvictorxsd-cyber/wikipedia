# Clãs

Os **clãs** permitem que jogadores do DropMC formem equipes para compartilhar experiências, organizar atividades e competir juntos no Survival. Seja para construir uma base com amigos ou reunir um grupo focado em competições, o sistema oferece recursos para gerenciar integrantes, criar uma identidade própria e fortalecer a colaboração.

## Informações principais

| Informação                 | Detalhes                |
| -------------------------- | ----------------------- |
| **Custo de criação**       | 10.000 coins            |
| **Limite de integrantes**  | 10 jogadores por clã    |
| **Tag**                    | Exatamente 3 caracteres |
| **Cor inicial da tag**     | Cinza, gratuita         |
| **Bandeiras iniciais**     | 8 modelos gratuitos     |
| **Bandeira personalizada** | 100 Cash                |

## Criação de um clã

Para criar seu próprio clã, você precisa ter **10.000 coins**. Com o valor disponível, abra o chat e digite:

`/clan criar <tag do clan> <nome do clan>`

Escolha uma **tag de 3 caracteres** e o nome do grupo. Em seguida, o servidor abrirá as opções de personalização para você selecionar a cor da tag e a bandeira.

A **cor cinza** e as **8 bandeiras padrão** podem ser escolhidas gratuitamente. Outras cores são adquiridas com Cash, enquanto uma **bandeira personalizada custa 100 Cash**.

Depois dessas escolhas, seu clã estará criado e pronto para receber integrantes.

Para acompanhar todas as etapas em detalhes, consulte [Como criar um clã](../guias-e-tutoriais/como-criar-um-cla.md).

## Integrantes e organização

Cada clã pode reunir **até 10 jogadores**. O sistema permite convidar novos integrantes e administrar a participação dos membros.

Algumas opções disponíveis incluem:

* **Convites:** envie um convite com `/clan convidar <jogador>`; o convidado pode aceitar pelo comando `/clan aceitar [convite]`.
* **Cargos:** utilize as opções de promover e rebaixar integrantes para organizar o grupo.
* **Liderança:** a liderança pode ser transferida para outro membro.
* **Saída e expulsão:** jogadores podem deixar o clã, e os responsáveis podem gerenciar seus integrantes.

## Comunicação e base do clã

Para facilitar a organização do grupo, o sistema possui um **chat próprio**, permitindo conversar com os integrantes sem enviar mensagens ao chat global.

Use `/clan chat` para alternar o modo de conversa. Também existem os atalhos `/.` e `/cc`.

Os clãs podem definir um ponto de encontro ou base:

* `/clan sethome`: define a localização da base.
* `/clan home`: teleporta para a base cadastrada.

## Alianças e rivalidades

Os clãs podem estabelecer relações com outros grupos do servidor.

* **Alianças:** permitem registrar uma relação de parceria entre clãs.
* **Rivalidades:** permitem declarar uma relação competitiva com outro clã.

Essas relações são gerenciadas pelos comandos de clã. Também existe uma configuração para **ativar ou desativar o fogo amigo** entre integrantes.

## Personalização

Além do nome e da tag, cada clã pode possuir uma identidade visual própria.

**Cores da tag:** a cor cinza é gratuita. Para utilizar outras cores, é necessário adquiri-las com Cash.

**Bandeiras:** o sistema oferece **8 modelos gratuitos**. Também é possível adquirir uma bandeira personalizada por **100 Cash**.

A moeda premium pode ser obtida por diferentes meios no DropMC. Para saber mais, consulte a página [Cash](cash.md).

## Competições e convivência

Os clãs podem reunir jogadores com objetivos casuais ou competitivos, incluindo o interesse em **eventos e ligas de clã**.

Independentemente da proposta do grupo, todos os integrantes devem respeitar as [Regras e Políticas do DropMC](../regras-do-servidor/regras-e-politicas-do-dropmc.md).

Para consultar a lista completa de comandos, incluindo convites, administração, alianças, rivalidades e personalização, acesse [Comandos de clãs](../comandos/clas.md).

Se precisar de ajuda, entre em contato pelo [Discord oficial](https://discord.gg/dropmc).
